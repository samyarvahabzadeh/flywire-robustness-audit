# Journal target ladder

Submission order (only one at a time; move down after rejection):

1. BioRxiv preprint (immediate; establishes priority).
2. Network Neuroscience (MIT Press, Q1). Scope fit: new network data/tools/methods. APC ~1750 USD (waiver possible). Framing: robustness framework + updated v783 analyses + public audit ledger.
3. eNeuro (SfN). Explicitly welcomes replications, null results, reanalyses of published data; 'Confirmation' article type = replicate + extend someone else's published result. Policy: limited additional-work demands (<3 months). Framing: Confirmation + framework.
4. Discover Neuroscience (Springer Nature). Broad scope incl. neuroinformatics; indexed WoS/Scopus; currently in APC-free period. Fast fallback.

Notes:
- Verify current APC/waiver terms at submission time.
- Keep paper as 'stability charter' (service framing), cite the original papers' own supplement robustness checks as motivation, not as flaws.
- If desk-rejected at 2-3 without reviews, submit as-is to the next rung within one week.
